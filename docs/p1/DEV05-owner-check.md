# DEV05 所有者による実エクスポートの確認手順

P-0005 の取り込みは、合成データでしか試験していない。実エクスポートの形式（エントリー構成、会話 ID の形式、日時、大きさ）が想定と合うかは、所有者が自分の端末で確かめる。実エクスポートとその内容を Issue・PR・AI エージェントへ渡さない（CLAUDE.md）。

## 手順

1. ChatGPT の設定から公式エクスポートを依頼し、届いた ZIP を保存する [S03]。
2. このリポジトリで `pnpm install --frozen-lockfile` と `pnpm build` を実行する。
3. Chrome の `chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」で `dist/` を読み込む。
4. 任意のタブで拡張のアイコンを押し、管理画面を開く。
5. 「エクスポートの ZIP ファイル」で保存した ZIP を選ぶ。
6. 表示された状態（完了 / 一部のみ / 失敗）、取り込み件数、問題のある項目、構造レポートを確認する。

## 報告してよいもの

- 状態、取り込み件数、問題項目のコードごとの件数（例: `unknown-entry` が 3 件、`invalid-id` が 0 件）。
- 構造レポートの内容。構造レポートはタイトル・本文・会話 ID・ファイル名・メールアドレスを含まないように作ってある。転記の前に、それらが含まれていないことを目で確かめる。

## 報告しないもの

- 問題項目の括弧内に出るファイル名（`unknown-entry` のときは ZIP 内の名前がそのまま出る）。拡張子の傾向だけを伝える。
- 会話のタイトル・本文、ZIP そのもの。

## 結果の扱い

- `unknown-entry` が出たファイルの種類、`invalid-id`・`invalid-time`・`invalid-tree` の件数、`conversationsUncompressedBytes` の大きさから、P-0005 の既知エントリーの一覧・ID 形式・上限を見直す後続の PR を作る。
- 失敗した場合は、問題項目のコードだけで原因を切り分ける。
