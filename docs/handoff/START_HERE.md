# 開発担当者への着手指示

## 開発目的

LizyChatTidyは、ChatGPTとClaude Code on the webの会話履歴を整理し、残す会話を保護しながら不要な会話を選択削除するOSS Chrome拡張である。開発者への会話送信、認証情報の取得、外部AI分類はしない。

## 最初の成果物

DEV01〜03を先行する。対象・除外・対応環境の表、公式根拠と未確認事項、操作別の公開条件、合成データのPoC、対象ID・アカウント/ワークスペースの識別方法、取得範囲と結果判定の証拠、リスク一覧を提出する。

ログイン済みのテスト環境がなければ未実施と報告する。DOM操作が理論上可能なだけで、自動削除できたことにしない。

## 変更してはいけない前提

- 対象を通常ClaudeチャットやローカルClaude CodeのJSONLへ置き換えない。
- 公開APIの適用方法が未確認のまま、APIキーで既存Web履歴を扱えるとしない。
- KEEPと主体の検証に失敗した場合は停止する。
- 削除対象を実行時に増やさない。不明な削除を自動再試行しない。
- 破壊的操作を本番履歴で試さない。実データをリポジトリ、AI開発エージェント、Issueへ渡さない。
- 個人利用、手動開始、OSS公開だけを許可の根拠にしない。

## 進め方

P0を終えてからP1の読み取り専用版へ進む。P2では操作補助と自動確定を分け、公開条件を満たす部分だけを有効化する。公開できない機能は条件と未達を明記する。

## 完了報告

実装範囲、commit、検証環境、テストIDと結果、未実施項目、残課題、公開可否を記載する。参考型定義は安全性の実装ではない。ランタイム検証と競合制御が別途必要である。
